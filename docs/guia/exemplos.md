# Exemplos

[`examples/app-users`](https://github.com/code-cfernandes/sashiko/tree/main/examples/app-users) traz CRUD, composição com `app.mount()`, mapeamento manual, guards, CORS, rate limit, logger, herança e injeção de dependências, além de um script que percorre todos os cenários:

```bash
pnpm dev
bash examples/app-users/scenarios.sh
```
